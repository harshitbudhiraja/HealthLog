# HealthLog

**Health Intelligence Platform** — Aggregate wearable data, track symptoms, detect anomalies, and generate AI-powered pre-visit briefs for clinicians.

Built with Indian healthcare standards in mind: DPDP Act 2023, ABDM-aligned, ICD-10 coded.

---

## Features

### Patient Dashboard
- Real-time wearable sync (Apple Health, Google Fit, Fitbit, Garmin, Oura Ring)
- Health logbook with timeline charts and anomaly detection
- Medication tracker and symptom logger
- AI-generated pre-visit briefs via Claude API

### Doctor Portal
- Patient brief review with longitudinal health views
- Annotate findings and flag anomalies
- Correlation engine across vitals, sleep, and reported symptoms
- Structured data export for EMR integration

---

## Security & Compliance

- AES-256 encryption at rest, TLS 1.3 in transit
- Data residency: `ap-south-1` (Mumbai)
- DPDP Act 2023 compliant
- ABDM-aligned data standards
- WCAG 2.1 AA accessible
